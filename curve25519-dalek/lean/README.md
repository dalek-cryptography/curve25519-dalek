# Lean verification of curve25519-dalek

Theorems about curve25519-dalek's public API in Lean 4, proved against an
[Aeneas](https://github.com/AeneasVerif/aeneas) translation of the Rust code.

## What to read

Only `ForHumans/`:

- `ForHumans/Specs/`: the definitions the theorems use (the curves, the RFC functions, the value
  of each Rust type and its invariants, the contracts assumed of `subtle`, `zeroize`, `alloc`).
- `ForHumans/Theorems/`: one file per Rust file, a theorem per public item. A theorem
  `f args ⦃ r => P r ⦄` says that `f args` returns some `r` (no panic, overflow or divergence)
  with `P r`.
- `ForHumans/TestVectors.lean` (optional): the definitions on the RFC test vectors.

Not to be read: `ForHumans/Theorems/<File>/` and `ForHumans/Specs/Representation/<File>/`
(generated from the `x86_64-tables` file by `scripts/gen-config-specs.py`), `Proofs/`, and
`Curve25519Dalek/` (generated by Aeneas).

Checks, run by the build:

- `ForHumans/Theorems/Axioms.lean`: the theorems use only Lean's axioms and the three crate
  contracts.
- `ForHumans/Theorems/Definitions.lean`: the theorems use no definition from `Proofs/`.
- `ForHumans/Theorems/Coverage.lean`: every translated function returning a point, table,
  precomputation or scalar has a theorem, or is in its exemption list.

## What the theorems cover

| Rust file | Theorems | Notes | Not covered |
|---|---|---|---|
| `scalar.rs` | `Scalar.lean` | A `Scalar` is its unreduced little-endian value `asNat`. A `HalfWidthScalar` has value `< 2^128`; constructors state it, consumers assume it. | Derived `Clone`/`Copy`; non-public items (`reduce`, `as_radix_16`, …, proved in `Proofs/Scalar/`). Not translated: `Debug`, `Hash`, `from_bits`, `random`, `hash_from_bytes`, `from_hash`, `group`, `serde`. |
| `traits.rs` | `Traits.lean` | Only the blanket `IsIdentity`; the other traits are covered with their implementing types. | |
| `edwards.rs` | `Edwards.lean` | Points via `toPoint` under `OnCurve`, `IsBounded`; tables via `point` under `IsTable`, `IsBounded`; precomputations via `points` under `IsValid`, `IsBounded`. Scalars act by `asNat < 2^255`. Iterators are given by the lists they yield. Multiscalar theorems are about the patched code (`translation-patches/edwards-*multiscalar_mul.patch`), which requires as many scalars as points. | Not translated: `Debug`, `Hash`, `group`, `serde`, `random`, hash-to-curve, provided trait methods. |
| `ristretto.rs`, `ristretto/elligator.rs` | `Ristretto.lean` | A `RistrettoPoint` is an `EdwardsPoint`; it stands for a ristretto255 element when even. Constructors state evenness. `ct_eq`/`eq` decide `Rel`. `compress`/`decompress` are RFC 9496 `encodeRep`/`decodeRep`, `from_uniform_bytes` is `fromUniformRep`, `map_to_curve` is `mapRep`. Multiscalar as for Edwards (`translation-patches/ristretto-*multiscalar_mul.patch`). | Derived `Clone`/`Copy`; `elligator_ristretto_flavor` (`pub(crate)`) and `coset4` (private), proved in their proof files. Not translated: `Debug`, `Hash`, `random`, `try_random`, `hash_from_bytes`, `from_hash`, `group`, `serde`. |
| `montgomery.rs` | `Montgomery.lean` | Inputs via `decodeUCoordinate`, results as `encodeUCoordinate`. Scalar multiplication is RFC 7748's ladder, computing `u(n • Q)` on the curve or its twist. | Not translated: `Debug`, `Hash`, `serde`. |
| `constants.rs` | `Constants.lean` | Includes the backend constants it re-exports. Tables exist only with precomputed tables. | `BASEPOINT_ORDER` (`pub(crate)`, proved in `Proofs/Constants/BasepointOrder.lean`). |

Configurations: each file states configuration-dependent items once, for `x86_64-tables`; the
copies for `i686-tables`, `x86_64-no-tables` and `i686-no-tables` are generated.

Not covered anywhere: code behind features that are not translated (only `alloc` and `zeroize`
are), and the SIMD and fiat backends. The invariants rely on the Rust fields staying private.

## Layout

| Library | Content |
|---|---|
| `ForHumans` | `Specs/`, `Theorems/`, `TestVectors.lean`. |
| `Curve25519Dalek` | The Aeneas translation. `FunsExternal.lean` and `TypesExternal.lean` are imported by name by the translation. |
| `Proofs` | The proofs and the lemmas they use. |

## Building

`lake exe cache get && lake build`. Check the generated copies with
`scripts/gen-config-specs.py --check`, regenerate them with `scripts/gen-config-specs.py`.

The Aeneas version is pinned in `AENEAS_VERSION.txt`. To regenerate the translation:
`scripts/aeneas-install.sh`, then `scripts/aeneas-translate.sh`.
